# 德育分签字表生成器

GUI 小工具，读取德育分 Excel 统计表，自动生成格式化 Word 签字确认表。

Excel 文件名、工作表、表头名称、列位置不固定，程序自动识别。

## 下载

进入 [Releases 页面](https://github.com/yyxi746/moral-score-sign-generator/releases)，下载最新版 `zixin-nxy.exe`，双击即可使用，无需安装 Python。

> 🧰 **如果提示 `Could not create temporary directory!`**：单文件版启动时要先把自身解压到系统临时目录，个别电脑上这一步会被安全软件拦住。这时改下载同一版本的 `zixin-nxy-onedir.zip`，解压后运行 `zixin-nxy\zixin-nxy.exe`（目录版不写临时目录，放在任何位置都能跑）。注意 exe 必须和同级 `_internal` 文件夹待在一起，换位置请整个文件夹一起挪。
>
> ⚠️ **首次运行提示「Windows 已保护你的电脑」是正常的**：程序没有购买数字签名证书，Windows SmartScreen 对「无签名 + 无下载量」的新程序一律先拦截。点弹窗里的 **「更多信息」→「仍要运行」** 即可，之后同一文件不会再拦。请只从上述 Releases 页面下载，并核对页面公布的 SHA256。

## ✨ 功能

1. 图形界面，无需命令行操作；单文件 / 批量处理两个页签
2. 自动识别姓名、德育总分、多组月份表扬信列，姓名列 / 总分列识别后可在下拉框手动调整；表扬信支持按月份段多选，无表扬信填 0
3. 批量处理：一次添加多个 Excel 或整个文件夹，支持把文件/文件夹直接拖入窗口，逐个分析生成、失败不中断、可中途取消；不同子文件夹下的同名文件自动加后缀区分、绝不互相覆盖
4. 批量列表双击查看文件详情：学生明细（姓名 / 德育分 / 表扬信条数）一目了然，并可手工修正该文件的 Word 标题与班级
5. 生成前结果预览：单文件页预览区显示全部学生（可滚动核对），分数异常行自动标黄；批量页双击任意文件即可在生成前核对标题、班级与完整学生明细
6. 生成前数据校验：分数为空、负数、非数字或人数为 0 的文件提前标黄提醒，避免签完字才发现错误
7. 首次运行自动引导选择 Word 模板；模板缺失时弹窗引导，不再生硬报错
8. 启动时自动检查新版本，状态栏提示并可点击前往下载，也可一键忽略该版本
9. 输出文件正在 Word 中打开时给出友好提示，单文件覆盖已有文件前先确认
10. 配置记忆：Word 模板路径、固定输出目录保存在系统 %APPDATA% 隐藏目录，程序目录不生成配置文件
11. 输出文件名自动将数据源文件名里的「统计表」替换为「签字表」
12. 自动生成 Word 标题，完整继承 Word 模板的表格样式、边框、字体，表头行跨页自动重复
13. 单文件页选错数据源可一键「清除」复位，重新选择；文件 / 文件夹可直接拖入窗口
14. 首次启动自动弹出「使用说明与反馈」，含数据复核提醒与反馈邮箱；关于窗提供「邮件反馈」按钮，可直接写信联系开发者
15. **证书/表扬信提取**（第三个页签）：针对「第3行大类、第4行细分、数据从第5行」的新模板统计表，按填写的名单从多个源表中提取；自动识别每个加分段（月份段不固定）的加分描述列与表扬信列，跨月份合并、去掉「（…）」括号备注与条目末尾的加分分值、次数标记（如 `+1`、`+0.5`、`*4`、`×4` 一律去除，只保留名称，开头日期如 7.5、8.31 保留），附加分（职务、六级证书等）不取；输出「姓名 | 证书 | 表扬信」三列 Excel，支持多文件拖入、名单每行一个姓名、未找到的人员弹窗提示；同名在多个源表出现时分行列出，并在末尾追加浅橙色「（合计）」汇总行
16. **句子形式转换**（第四个页签）：把第三页签生成的结果 Excel 转成完整句子后另存（文件名自动加“_句式”）；证书按类型自动加前缀——竞赛/奖项/名次类（含“奖”、第几名、竞赛、比赛等）加「荣获」，荣誉称号类（三好学生、好室友、百佳寝室、学霸宿舍、标兵、最美、优秀等）加「被评为」，并去掉「证书」二字，无法判断的默认「荣获」；表扬信每条统一加「参与」；条目顺序保持不变，浅橙色「（合计）」行也会一并转换；支持多文件拖入批量转换
17. **界面体验优化**：文件列表为空时显示灰色占位提示（“把 Excel 拖到这里，或点上方添加文件”）；第四页签「使用说明」改为可折叠按钮，默认收起更简洁；提取/转换/生成时状态栏显示“正在处理…”，完成后恢复；四个页签底部主按钮间距统一；切换页签时只在首次进入给建议窗口尺寸，之后不再强制重置，保留用户手动缩放后的大小，最小窗口下调至 720×560 适配小屏

## 打包 exe

依赖已写入 `requirements.txt`（含 pyinstaller）。两个版本都要打，一起发：

```bash
# 1) 主推：单文件版 → dist/zixin-nxy.exe（双击即用）
pyinstaller --onefile --noconsole --name zixin-nxy --icon app.ico \
  --version-file version_info.txt --add-data "app.ico;." \
  --collect-all tkinterdnd2 main.py

# 2) 兜底：目录版 → dist/zixin-nxy/，整个文件夹压成 zixin-nxy-onedir.zip
pyinstaller --onedir --noconsole --name zixin-nxy --icon app.ico \
  --version-file version_info.txt --add-data "app.ico;." \
  --collect-all tkinterdnd2 main.py
```

单文件版启动时要把自身解压到 `%TEMP%`，个别电脑上会被安全软件拦住并报 `Could not create temporary directory!`，所以目录版作为兜底一起发；两次打包别用同一个 `--distpath`，否则后一次的产物会盖掉前一次的。

版本号改两处：`main.py` 里的 `APP_VERSION` 与 `version_info.txt` 里的 `filevers/prodvers`。
