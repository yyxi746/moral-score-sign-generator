\# 德育分签字表生成器

GUI小工具，读取德育分Excel统计表，自动生成格式化Word签字确认表。

Excel文件名、工作表、表头名称、列位置不固定，程序自动识别。



\## ✨功能

1\. tkinter图形界面，无需命令行操作

2\. 自动识别姓名、德育总分、多组月份表扬信列，支持勾选指定月份，无表扬信填0

3\. 配置记忆：Word模板路径、固定输出目录，配置保存在系统%APPDATA%隐藏目录，程序目录不会生成配置文件

4\. 输出文件名自动将数据源文件名里【统计表】替换为【签字表】

5\. 自动生成Word标题，完整继承Word模板的表格样式、边框、字体
